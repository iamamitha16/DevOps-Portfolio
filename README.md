# Task 6 – Host a Static Website with GitHub Pages

## Elevate Labs – DevOps Internship

### Project Overview
This project demonstrates how to create and host a static website using HTML, CSS, Git, GitHub, and GitHub Pages.

The website is a personal DevOps portfolio that introduces my technical skills, learning journey, and projects.

### Objective
To deploy a static HTML website using GitHub Pages and make it accessible through a public URL.

### Tools Used
- HTML
- CSS
- Git
- GitHub
- Git Bash
- Visual Studio Code
- GitHub Pages

### Project Structure
```text
DevOps-Protofolio/
├── index.html
├── style.css
└── README.md
```

### Implementation Steps
1. Created the project folder and developed the website using HTML.
2. Designed the website using CSS.
3. Initialized a Git repository and committed the project files.
4. Created a GitHub repository and pushed the files using Git Bash.
5. Configured GitHub Pages to deploy from the `main` branch and root folder.
6. Verified that the website was published and accessible online.

### Outcome
Successfully deployed a personal DevOps portfolio website using GitHub Pages. The website displays information about my technical skills and projects and is accessible through a public URL.

- **Live Website:** https://iamamitha16.github.io/DevOps-Portfolio/

### Conclusion
This task helped me understand static website hosting, Git version control, GitHub repository management, and the deployment process using GitHub Pages. It also provided practical experience in publishing a website online.
